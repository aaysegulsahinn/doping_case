
# Fateful Moment - React Native Case

## Kurulum
1. `npm install`
2. `npx expo start`
3. Expo Go ile QR kodu okutun (iOS/Android)

## Kullanılan AI Araçları ve Yaklaşım
Bu proje Claude (Anthropic) ile birlikte geliştirilmiştir. Figma tasarımı 
ekran ekran incelenip, React Native (Expo Router) ile TypeScript kullanılarak 
kodlanmıştır. Dummy data ile auth ve senaryo akışı simüle edilmiştir.
Video oynatma için expo-video, DNA radar chart için react-native-svg 
kullanılmıştır.

## Notlar
- Backend yoktur, tüm veri dummy'dir (data/dummyData.ts)
- Android APK: EAS Build ile alınmıştır
